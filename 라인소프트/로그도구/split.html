로그 일자 분할

통으로 된 로그를 일자별로 나누고, 월 → 일 계단 폴더로 정돈합니다. 작은 파일은 ZIP으로, 수 GB 로그는 폴더로 직접 저장합니다. 처리는 브라우저에서만 하며 서버로 올라가지 않습니다.

로그 넣기

로그 파일을 여기에 놓거나 클릭해서 선택 .log · .txt · .out 등 여러 개 가능
선택된 파일 없음. 파일이 없으면 아래 텍스트를 사용합니다.

라인소프트 EAP [2026-03-01 20:33:16:1061] 형식, logback 시작 로그, 스택 트레이스, JSON 본문을 지원합니다. 날짜는 줄 앞 타임스탬프만 사용합니다.

분할 옵션

폴더로 저장할 때는 빈 폴더를 새로 만들어 고르세요. C:\, 사용자 홈, Windows, Program Files, 바탕화면은 Chrome이 시스템 폴더로 막습니다. 예: D:\로그분할 또는 다운로드 안의 새 폴더.

정돈된 폴더

분할하면 월 → 일 폴더 구조가 여기에 보입니다.

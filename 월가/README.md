# 월가 의도 트래커

경제지표가 아니라 **월가가 지금 어느 바구니에 돈을 넣는지**를 읽고, 따라갈 슬롯을 제시하는 로컬 대시보드입니다.

`주식/`, `백데이터/`와 코드·데이터·가상환경을 공유하지 않습니다. 이 폴더의 `.venv`만 사용합니다.

## 실행

`run.bat` 을 더블클릭하거나:

```bat
run.bat
```

브라우저에서 Streamlit 앱이 열립니다. 첫 실행은 FRED·Yahoo 수집 때문에 1~2분 걸릴 수 있습니다.

## 이 앱이 답하는 질문

1. 지금 월가를 따라갈 구간인가 (RISK_ON / MIXED / RISK_OFF)
2. 주식·채권·금·현금 중 어디에 넣는가 (확대 / 유지 / 축소 / 회피)
3. 그 신호가 과거에 가격을 갈랐는가 (한눈 검증 차트)

개별 주식 종목, 목표가, 손절, 자동매매는 하지 않습니다.

## 데이터

- 일간 골격: FRED CSV (키 없음)
- 장중 테이프: Yahoo Finance, 미국 정규장 중 약 3분마다 갱신
- 미국 정규장: 서머타임 22:30~05:00 KST, 겨울 23:30~06:00 KST

Yahoo는 0~15분 지연이 있을 수 있습니다.
